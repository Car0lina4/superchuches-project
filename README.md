# Superchuches local

## Arranque

```bash
npm install
npm run dev
```

Después abre en el navegador la URL que te indique Vite, normalmente:

```bash
http://localhost:5173
```

## Estructura

- `public/images/` contiene las imágenes ya enlazadas
- `src/App.jsx` contiene la landing
- `src/styles.css` contiene los estilos

## Siguiente paso sugerido

Puedes publicar luego en Vercel sin demasiado cambio, o pasar esta base a Next.js si prefieres.
